# ERSEC 29.0.0 — V19

## New roadmap foundation

- Universal Assessment Workspace and provenance-aware Security Behavior Attack Graph remain integrated.
- Security Boundary Lab adds deterministic identity/tenant/object/field authorization planning and offline evaluation.
- Credential values are rejected; only explicit credential references are accepted.
- Missing evidence remains `not_tested` and cannot become PASS.
- Proof Engine creates independently verifiable controlled differential evidence bundles.
- Proof integrity digests are explicitly not signatures or compromise claims.

## Validation

- Built-in ERSEC self-test: 66/66 PASS.
- Workspace + attack graph + Security Boundary Lab + Proof Engine focused tests: 12/12 PASS.
