# ERSEC 29.1.1 Counterfactual Assurance

ERSEC 29.1.1 compares evidence from an authorized baseline and a controlled policy mutation. A baseline PASS followed by a mutation VIOLATION establishes that the observed security property is sensitive to the mutation. Same-verdict and unexpected-improvement cases remain INCONCLUSIVE.

No target is contacted by the counterfactual evaluator and it does not generate exploits.
