# Authorization Benchmark v7

Version 7 turns the ERSEC authorization laboratory into an external-comparison-ready artifact while preserving its controlled scope.

## Dimensions

Every case is classified independently by truth class, relationship, API version, field-policy coverage, and state context. Policy truth remains separate from observed detector verdicts.

## Safety

The corpus remains synthetic, loopback-only, GET-only, and state-preserving. It contains no external targets or raw credential values.

## Comparison rule

ERSEC may publish results from this corpus only after independent truth review. The corpus digest and benchmark manifest identify the exact case set. Competitor results must use the same cases, truth policy, safety constraints, and reporting rules to support a fair comparison.
